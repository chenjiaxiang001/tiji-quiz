# 题迹

本地优先的刷题 PWA。题库、练习记录、错题状态均保存在当前设备，不需要后台服务。

## 已实现

- 内置当前 252 道人力资源题库，首次打开即可练习。
- 从 `.xlsx`、`.xls` 或 `.csv` 导入新题库，导入前校验题型、序号、题目和答案。
- 按题型、顺序、随机或错题进行练习。
- 单选题、多选题自动判分。
- 填空题给出比对建议，简答题和填空题由用户自评掌握情况。
- 错题自动收集、待复习/已掌握状态、错题重练。
- 保存练习批次、每道题的答案、结果、耗时和主观题自评。
- 按题型统计正确率、今日学习、累计作答和连续学习天数。
- 完整 JSON 备份与恢复。
- 响应式桌面和移动端布局。
- PWA 离线缓存，可安装到桌面或手机主屏幕。

## 本地开发

需要 Node.js 20 或更高版本。

```bash
pnpm install
pnpm dev
```

生产构建与测试：

```bash
pnpm test
pnpm build
pnpm preview
```

构建结果位于 `dist/`。

## 部署

这是一个纯静态应用，没有后端、数据库或环境变量。将 `dist/` 上传到任意支持 HTTPS 的静态托管即可。

适合 MVP 的低成本方式：

- Cloudflare Pages：连接代码仓库或直接上传 `dist/`，常规免费额度足够个人和小范围使用。
- GitHub Pages：适合已有仓库，上传构建后的静态文件。
- 任意自有静态服务器：可部署到子目录，构建已使用相对资源路径。

PWA 安装和 Service Worker 需要 HTTPS；`localhost` 开发环境除外。首次加载后再断网仍可使用，数据不会上传。

## 数据与备份

数据使用浏览器 IndexedDB 保存在当前站点来源下。以下情况会使本地数据不可访问：

- 清除浏览器网站数据；
- 更换浏览器、域名或设备；
- 卸载浏览器并清除应用数据。

页面内的“导出完整备份”会生成一个 JSON 文件，包含所有题库、练习批次、作答记录、错题状态和当前题库设置。建议定期导出并保存到其他设备。

## 题库格式

导入工作表至少需要以下四列：

| 题型 | 序号 | 题目 | 正确答案 |
|---|---|---|---|
| 单选题 | 1 | 题干 | A |

可选列为 `选项1` 到 `选项5`、`参考制度`。支持题型为 `单选题`、`多选题`、`填空题`、`简答题`。

重新生成内置题库：

```bash
pnpm seed
```

默认读取根目录的 `人力题库.xlsx` 并写入 `src/data/seed.json`。也可以传入输入和输出路径。

## 说明

- 不同设备之间不会自动同步，需要手动导出和恢复备份。
- 当前题库只提供参考答案和参考制度，没有逐题详细解析。
- 客户端应用中包含题库内容；如果题库需要保密，应使用受访问控制的内网托管。
